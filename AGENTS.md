# UTC RAG Portfolio

Static landing page and RAG portfolio for UNIDA Technology Care (UTC).

- Frontend: HTML, CSS, and vanilla JavaScript.
- Backend: FastAPI with Sentence Transformers retrieval and optional Gemini generation.
- Curated public knowledge is in `data/knowledge-base.json`; other `data/` files are internal and ignored by Git.
- Secrets belong in `.env`, never in committed source.
